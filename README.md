# Inflation-Calc-Skill
货币银行学课程作业：GitHub发布专属AI Skill

## 项目简介
本项目是面向货币银行学的自定义Skill。
输入本期CPI、上期CPI、名义存款利率，自动计算通货膨胀率，并且通过费雪效应近似公式得到实际利率。
可以作为大模型外部工具调用，输入经济参数，返回结构化计算结果和金融学原理。
> 本项目和其他同学利息计算器、货币政策分析工具不重复。

## 理论公式
1. 通货膨胀率：
$$通胀率=\frac{CPI_{本期}-CPI_{上期}}{CPI_{上期}} \times 100\%$$
2. 费雪近似公式（实际利率）：
$$实际利率 ≈ 名义利率 - 通货膨胀率$$

## 功能说明
1. 接收3个经济参数：本期CPI、上期CPI、名义利率
2. 自动计算通货膨胀率
3. 计算实际利率
4. 返回结果附带金融学原理说明
